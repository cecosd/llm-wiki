# wiki-lint

1. Изпълни `npm run lint`. Прочети генерирания `outputs/lint-mech-YYYY-MM-DD.md`.
2. Поправи механичните проблеми, които са безопасни (счупени връзки с очевидна цел, липсващи записи в index.md). Сирачетата свържи от подходящ topic хъб.
3. Смислова проверка (чети по тема, не всичко наведнъж):
   - противоречия между страници;
   - твърдения, изместени от по-нов източник;
   - често споменавани понятия без страница (виж секцията „Липсващи страници“ в отчета);
   - `confidence: low` страници;
   - теми с един единствен източник.
4. Запиши `outputs/lint-YYYY-MM-DD.md`: какво е поправено, какво чака решение от човека, препоръки за четене.
5. Запис `lint` в `wiki/log.md`.
