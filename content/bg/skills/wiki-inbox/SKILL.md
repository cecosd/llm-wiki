# wiki-inbox

1. Изпълни `npm run inbox`. Покажи накратко кой файл къде отиде.
2. Ако някой файл е сортиран грешно (напр. кратка книга в papers/), кажи на човека и предложи `npm run inbox -- --move <файл> <папка>`. Не местиш сам без съгласие.
3. Изпълни `npm run extract`. Ако някой PDF даде празен текст, вероятно е сканиран: отбележи го като нуждаещ се от OCR.
4. Изпълни `npm run status` и покажи списъка с необработени файлове.
5. Добави запис `inbox` в `wiki/log.md`.
6. Попитай с кой файл да започне ingest (или „всички“).
