# Glossary

| Word | Meaning |
|---|---|
| **wiki** | The `wiki/` folder with the pages the AI writes. |
| **raw** | The `raw/` folder with your original files. Never changed. |
| **Source** | The page for one raw file: summary, emphasis, APA reference. |
| **Chapter** | The page for one chapter of a book. |
| **Concept** | An idea, theory, method. One page even when used in several areas. |
| **Person, organisation** | A page for a person, organisation, tool, work. |
| **Topic** | A hub that groups concepts and sources. |
| **Emphasis** | What the source itself puts weight on. |
| **Kind of text** | What "Write with the wiki" writes: a scientific article, an essay, popular science, a literature review or fiction. |
| **Creativity** | From 1 (strict) to 5 (bold): how free the style and the interpretation are when writing. The facts and the citations still come only from the library. |
| **Blank document** | A text you write yourself; the model helps paragraph by paragraph. |
| **Based on** | The list of sources under a piece of fiction, which has no citations in the text itself. |
| **Area** | The area of knowledge of a source (1 to 3 words). |
| **Alias** | Another spelling or translation of the same name. |
| **p. N** | A PDF page number that opens the reader. |
| **Token** | The unit in which models count text and price. |
| **Agent** | A model with tools (Claude Code) that opens files itself. |
| **API** | A connection to a provider with a key, without tools. |
| **Context** | How much text the model takes at once. |
| **OCR** | Recognising text from a picture or a scanned PDF. |
| **Launcher** | `scripts/app.js`: starts the server and the window hidden. |
| **Safe mode** | Running with limited rights ([see](#/docs/safe-mode)). |
| **bubblewrap** | A Linux tool for a "cage" around a program. |
| **Node.js permissions** | `node --permission`: limits the files Node can reach. |
| **hosts** | A system file where a name is pointed to an address. |
| **localhost** | The address of your own computer (`127.0.0.1`). |
| **DNS rebinding** | An attack where another site points a name at `127.0.0.1` to read a local server. |
| **Frontmatter** | The block of data at the start of a page (title, type, sources...). |
| **Lint** | A health check of the wiki. |
| **Ingest** | Processing a new source. |
