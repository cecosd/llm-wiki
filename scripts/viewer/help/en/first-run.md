# First start

On the first opening you see the welcome screen. It has three jobs.

## 1. The tour

The "1-minute tour" button highlights the real buttons one by one and says what each is for. You can run it again from the menu **Help → Welcome and tour**.

Three of the steps open **Write with the wiki** and show the choices themselves: the kind of text (scientific article, essay, popular science, literature review, fiction), who writes and how freely (level and creativity from 1 to 5) and "Blank document" for a text of your own. At the end the tour takes you back where it started. In detail: [Learning and writing](#/docs/learn-write).

## 2. How it works

Four cards (Add, Process, Read and search, Learn and write) show where each step is done.

## 3. Choosing the AI

Four big cards take you to [Settings → Model](#/settings/model) with a suitable profile already selected:

| Card | When |
|---|---|
| Claude | You have a Claude subscription or key. |
| Another provider with a key | ChatGPT, Gemini (a free tier exists), Groq, DeepSeek, Mistral. |
| A model on this computer | Ollama or LM Studio: free, and nothing leaves the computer. |
| No account | You copy requests into a browser chat and bring the answers back. Slow but free. |

Nothing is installed and nothing is sent until you press a button. Details: [Choosing a model](#/docs/choose-model).

## The checklist

At the bottom there is a "Ready to start?" list: model, mode, site name (optional) and first file. "Skip for now" hides the screen; bring it back from the Help menu.

## What it asks later

- If you chose Claude Code and it is not installed or you are not signed in, the **Setup** screen says exactly what to do. It is needed only for that choice.
- If you choose another way, Claude Code is not needed at all.
