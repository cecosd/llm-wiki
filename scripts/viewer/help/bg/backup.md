# Резервни копия и архив

Библиотеката е папка на един диск. Ако дискът умре, всичко е загубено, затова направи поне едно копие другаде.

## Резервно копие и споделяне

**Настройки → Резервни копии** (и бутонът в менюто). Целта е всяка папка: втори диск, мрежов диск, Google Drive, Dropbox, OneDrive, pCloud Sync. Има три вида цели:

| Вид | Поведение |
|---|---|
| Резервно копие | Винаги записва нашето състояние, не пита. |
| Обща папка | Ако в нея има чужди промени, пита дали да се вземат или презапишат; при една страница слива абзац по абзац. |
| Само взема | Взема от копие на колега. |

Проверката е само при поискване („Провери копието“); няма таймер. Заменените версии отиват в `_deleted/`. Ключовете и паролата не се копират по подразбиране. Подробен наръчник: `docs/backup-and-sharing.bg.md` в папката на проекта.

## Възстановяване

```
npm run restore -- <папка>            # само показва
npm run restore -- <папка> --apply    # връща
```

## Архив за четене

**Настройки → Архив за четене → Направи архива** прави един ZIP със страниците и текста на книгите (без оригиналните PDF). Отваря се с двоен клик върху `index.html`, работи без сървър и без интернет. Не е резервно копие: от него не се възстановява библиотеката.

## Ограничение

В [защитен режим](#/docs/safe-mode) (и при двата вида защита) копията към други папки са изключени, защото програмата не може да пише извън проекта. Направи копието в обикновен режим.
