# Работа с Claude Code

Освен през интерфейса, библиотеката може да се води направо от Claude Code в терминала. Това е режимът „агент“: Claude отваря файловете и пише страниците по правилата на проекта.

## Подготовка

1. Инсталирай Claude Code от [документацията на Anthropic](https://docs.claude.com/en/docs/claude-code/setup) и влез веднъж с `claude`.
2. В папката на библиотеката пусни `claude`. Той чете автоматично `CLAUDE.md` (правилата на wiki-то) и, ако съществува, `CLAUDE.local.md` (личните ти предпочитания, извън Git).

## Скилове

Скиловете са в `.claude/skills/` и се викат с наклонена черта:

| Команда | Какво прави |
|---|---|
| `/wiki-inbox` | Сортира `raw/inbox/`, извлича текста, показва какво чака. |
| `/wiki-ingest` | Обработва новите raw файлове: страница на източника, глави, понятия, индекс, дневник. |
| `/wiki-chapters <slug>` | Добавя страници по глави към вече обработена книга. |
| `/wiki-upgrade <slug>` | Надгражда стар източник до текущия стандарт. |
| `/wiki-query <въпрос>` | Отговаря от wiki-то, с цитати. |
| `/wiki-synthesis [етикет]` | Сравнения, тематични хъбове, празнини. |
| `/wiki-lint` | Механична и смислова проверка. |

## Правилата в `CLAUDE.md`

- `raw/` не се променя.
- Frontmatter във всяка страница; цитати като `([[източник-ch03]], с. 53)`; `с. N` е номерът на PDF страницата от маркера `<!-- стр. N -->`.
- Нова страница има поне една входяща връзка; противоречията са в `## Противоречия`.
- Езикът на страниците е езикът на съдържанието (български или английски).

Промяна на правилата: редактирай пакета в `content/<код>/` и пусни `npm run content -- <код>`, иначе следващата смяна на език връща старото.

## Нещо друго от Claude

Ако ползваш друг модел през Claude Code (Ollama, DeepSeek), настрой профила в интерфейса: той подава нужните променливи на средата. Подробно: [Избор на модел](#/docs/choose-model).

## Не чете тайни

Файловете с ключове и настройки (`.library-secrets.json`, `.library-auth.json`, `library.config.json`) са забранени за четене от агента.
