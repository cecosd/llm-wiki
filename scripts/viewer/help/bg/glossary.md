# Речник

| Дума | Значение |
|---|---|
| **wiki** | Папката `wiki/` със страниците, които пише ИИ. |
| **raw** | Папката `raw/` с твоите оригинални файлове. Не се променя. |
| **Източник** | Страница за един raw файл: резюме, акцент, цитат в APA. |
| **Глава** | Страница за една глава на книга. |
| **Понятие** | Идея, теория, метод. Една страница, дори да се ползва в няколко области. |
| **Личност, организация** | Страница за човек, организация, инструмент, произведение. |
| **Тема** | Хъб, който групира понятия и източници. |
| **Акцент** | Върху какво поставя тежест самият източник. |
| **Вид текст** | Какво пише „Писане с wiki“: научна статия, есе, научно-популярна статия, обзор на литературата или художествен текст. |
| **Креативност** | От 1 (строг) до 5 (смел): колко свободни са стилът и тълкуването при писане. Фактите и цитатите остават само от библиотеката. |
| **Празен документ** | Текст, който пишеш сам; моделът помага абзац по абзац. |
| **По мотиви от** | Списъкът с източници под художествен текст, който няма цитати в самия текст. |
| **Област** | Област на знанието на източника (1 до 3 думи). |
| **Псевдоним (alias)** | Друго изписване или превод на същото име. |
| **с. N** | Номер на PDF страница, който отваря четеца. |
| **Токен** | Единица, по която моделите броят текст и цена. |
| **Агент** | Модел с инструменти (Claude Code), който сам отваря файлове. |
| **API** | Връзка с доставчик чрез ключ, без инструменти. |
| **Контекст** | Колко текст побира моделът наведнъж. |
| **OCR** | Разпознаване на текст от снимка или сканиран PDF. |
| **Стартер** | `scripts/app.js`: пуска скрито сървъра и прозореца. |
| **Защитен режим** | Пускане с ограничени права ([виж](#/docs/safe-mode)). |
| **bubblewrap** | Инструмент на Linux за „клетка“ около програма. |
| **Права на Node.js** | `node --permission`: ограничава файловете, до които стига Node. |
| **hosts** | Файл на системата, в който име се насочва към адрес. |
| **localhost** | Адресът на твоя компютър (`127.0.0.1`). |
| **DNS rebinding** | Атака, при която чужд сайт насочва име към `127.0.0.1`, за да чете локален сървър. |
| **Frontmatter** | Блокът с данни в началото на страницата (заглавие, вид, източници...). |
| **Lint** | Проверка на здравето на wiki-то. |
| **Ingest** | Обработка на нов източник. |
