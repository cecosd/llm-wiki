# Настройки и променливи

## Файлове

| Файл | Какво съдържа | В Git? |
|---|---|---|
| `library.config.json` | Настройки: модел и доставчик (`ai`), език на съдържанието (`contentLang`), копия (`sync`), режим на обработка, `setupDone`, `welcomeDone`. | не |
| `.library-secrets.json` | API ключовете (0600). | не |
| `.library-auth.json` | Хеш на паролата за интерфейса. | не |
| `.launch.json` | Режим, име на сайта и порт на стартера. | не |
| `outputs/` | История на обработките, дневник на сървъра (`server.log`), колекции, отчети. | не |

Нищо от горното не се редактира по време на работа на сървъра, освен през интерфейса.

## Променливи на средата

| Променлива | Ефект |
|---|---|
| `PORT` | Порт на сървъра (4321 по подразбиране). |
| `WIKI_HOST` | Допълнително име на сайта, което сървърът приема (трябва да е в `hosts`). |
| `LIB_LANG` | Език на конзолните съобщения. |
| `LIB_AI_KEY` | Ключ за избрания доставчик (вместо файла). Има и типичните: `OPENAI_API_KEY`, `GEMINI_API_KEY`, `GROQ_API_KEY`, `DEEPSEEK_API_KEY`, `MISTRAL_API_KEY`, `OPENROUTER_API_KEY`, `ANTHROPIC_API_KEY`. |
| `LIB_BROWSER` | Път до браузър за прозореца на приложението (Chromium-основан). |
| `LIB_SANDBOX=off` | Само за `wsl-start.sh`: изключва клетката. |
| `CLAUDE_BIN` | Път до `claude`, ако не е в PATH. |
| `LIBRARY_OCR=builtin` | Принуждава вградения OCR вместо `ocrmypdf`. |
| `LIB_LAUNCHER`, `LIB_MODE`, `LIB_ISOLATION` | Слага ги стартерът; казват на сървъра как е пуснат. Не ги задавай. |

## Основна защита ръчно

Стартерът пуска сървъра така (Node 23+):

```
node --permission --allow-fs-read=<проект> --allow-fs-write=<проект>/wiki ... --allow-child-process --allow-worker scripts/server.js
```

Ако искаш друга папка за четене, подай я в `extraRead` на `permissionArgs` в `scripts/modes.js`.

## Обновяване на пакети

**Настройки → Обновления** показва кои пакети имат безопасна нова версия (в рамките на `package.json`) и ги обновява с `npm update --ignore-scripts`, после рестартира. Основните версии остават като команда за копиране. Минимумът е Node.js 24.
