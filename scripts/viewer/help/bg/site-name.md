# Име на локалния сайт

По подразбиране библиотеката е на `http://localhost:4321/`. Ако искаш свое име (например `biblioteka.test`), програмата го записва във файла **hosts** на системата. Името важи само на този компютър, във всички браузъри.

## Как се прави

**Настройки → Адрес на сайта**:

1. Напиши име. Предложения: `biblioteka.test`, `my-library.test`, `wiki.localhost`.
2. Натисни **Запази името**. Системата показва свой прозорец за разрешение на администратор (в Windows UAC, в macOS парола, в Linux прозорец на polkit). Програмата не вижда паролата ти.
3. Сървърът се рестартира и страницата се отваря на новия адрес. Портът остава в адреса (`http://biblioteka.test:4321/`).

Името се маха с **Махни името**.

## Правила за името

- Букви, цифри и тирета; части, разделени с точка; до 4 части.
- Не може да е `localhost` или само цифри.
- **Предпочитай `.test`, `.localhost`, `.local`, `.lan`, `.internal`.** Тези окончания не водят към истински сайтове. Ако сложиш име като `google.com`, този сайт няма да се отваря на компютъра ти; програмата иска изрична отметка за такива имена.
- Име без точка работи, но в адресната лента на браузър се търси в мрежата.

## Какво се случва във файла

Добавя се само блок:

```
# llm-wiki begin
127.0.0.1 biblioteka.test
::1 biblioteka.test
# llm-wiki end
```

До файла остава резервно копие `hosts.llm-wiki.bak`. Файловете:

| Система | Път |
|---|---|
| Windows | `C:\Windows\System32\drivers\etc\hosts` |
| macOS, Linux | `/etc/hosts` |
| WSL | на Windows (браузърът е там), същият път през `/mnt/c/...` |

## Защо сървърът приема само това име

Сървърът отговаря само за `localhost` и за записаното име. Така друг сайт, който сочи към `127.0.0.1` (атака „DNS rebinding“), не може да чете библиотеката ти.

## От терминала

```
sudo node scripts/hosts.js set biblioteka.test   # Linux, macOS
node scripts/hosts.js set biblioteka.test        # Windows, терминал като администратор
node scripts/hosts.js show
node scripts/hosts.js remove
```

След ръчна промяна рестартирай библиотеката с `WIKI_HOST=biblioteka.test` или чрез `npm run app` (стартерът чете `.launch.json`).

## Ако не работи

Изчисти кеша на DNS (`ipconfig /flushdns` в Windows), изключи „Secure DNS“ в браузъра за локални имена и виж [Когато нещо не работи](#/docs/troubleshooting).
