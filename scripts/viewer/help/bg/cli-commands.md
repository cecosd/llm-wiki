# Команди

Изпълняват се в папката на библиотеката (`npm run <име>`).

## Работа с файлове и страници

| Команда | Какво прави |
|---|---|
| `npm run inbox` | Сортира `raw/inbox/` по папки и записва в `raw/manifest.json`. |
| `npm run extract` | Извлича текст от PDF, DOC/DOCX, XLSX, CSV, EPUB, HTML в `raw/.extracted/` (само файлове в `raw/`). |
| `npm run status` | Кои raw файлове още нямат страница на източник. |
| `npm run pending` | Само новите файлове, по един път на ред: списъкът за обработка. |
| `npm run fix-paths` | Привежда `raw_path` в страниците към точния път на диска. |
| `npm run new -- <вид> <slug>` | Нова страница от шаблон. |
| `npm run index` | Строи наново `index.md`, `log.md`, `overview.md` (при загубени файлове). |
| `npm run lint` | Механична проверка: счупени връзки, сираци, липсващ frontmatter; отчет в `outputs/`. |
| `npm run lint:quick` | Само счупените връзки. |

## Управление

| Команда | Какво прави |
|---|---|
| `npm run remove -- <слъг>` | Преглед на премахване на източник (прилага се с `--apply`). |
| `npm run dupes` | Възможни дубликати; `npm run dupes -- <запази> <махни> [--apply]` ги обединява. |
| `npm run merge-sources -- "Заглавие" <слъг1> <слъг2> [--apply]` | Слива отделно качени глави в книга. |
| `npm run archive` | ZIP архив за четене. |
| `npm run sync -- list\|plan <име>\|run <име> [--push-only\|--overwrite]` | Резервни копия и синхронизация. `--overwrite` презаписва чужди промени: само по изрична причина. |
| `npm run restore -- <папка> [--apply]` | Връща библиотеката от копие. |
| `npm run content -- <bg\|en>` | Сменя езика на съдържанието (правилата, скиловете, шаблоните). |

## Сървър и приложение

| Команда | Какво прави |
|---|---|
| `npm run app` | Стартер: скрит сървър и прозорец ([виж](#/docs/cli-launch)). |
| `npm run serve` | Сървър на преден план. |
| `npm run serve:safe` | Сървър в клетка (bubblewrap). |
| `npm run sandbox:check` | Какво се вижда отвътре на клетката. |

## Разработка

| Команда | Какво прави |
|---|---|
| `npm test` | Тестове във временно копие с фалшив Claude. Не пипа библиотеката и не харчи токени. |
| `npm run i18n:check` | Липсващи и излишни преводи на интерфейса. |
| `npm run docs` | Копира библиотеките за страницата на продукта. |
| `npm run release:docs` | Преди издание: обновява отчета с тестовете. |

Всички скриптове, които пипат файлове, работят само в папката на проекта.
